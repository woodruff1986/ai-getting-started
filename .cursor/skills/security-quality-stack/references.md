- Bibliothèque massive de skills cybersécurité structurés.
- Bonne base pour:
  - enrichir playbooks d'analyse,
  - mapper workflows sécurité à des frameworks,
  - standardiser checklist sécurité par domaine.

## stop-slop (hardikpandya)
- Skill de nettoyage de prose pour supprimer:
  - formulations génériques IA,
  - structures rhétoriques répétitives,
  - remplissage inutile.
- Très utile pour documentations, PR descriptions, specs et comptes rendus.

## Intégration recommandée

1. Avant exécution sensible:
   - appliquer un mini threat check (actifs, menaces, impacts, mitigations).
2. Pendant exécution:
   - tracer décisions sécurité et hypothèses.
3. Avant livraison:
   - appliquer une passe "stop-slop" sur les livrables textuels.
4. Après livraison:
   - ajouter les incidents/contre-mesures validés dans la mémoire persistante.
